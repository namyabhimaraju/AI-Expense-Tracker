# AI Expense Tracker

A modern expense-tracking web app with AI-powered features (e.g., expense categorization, summaries), built with React, Vite, Tailwind, and Google GenAI. Includes a small Express backend for API endpoints and export functionality (PDF via jsPDF).

Status: WIP — use, test, and contribute!

---

## Features

- Add, edit, and delete expenses
- Auto-categorization and smart summaries using Google GenAI
- Interactive charts and visualizations (Recharts)
- Export reports to PDF (jsPDF)
- Responsive UI built with Tailwind CSS
- Local development with Vite


---

## Tech stack

- Frontend: React 19, Vite
- Styling: Tailwind CSS
- Charts: Recharts
- Backend: Express (optional server endpoints)
- AI: @google/genai
- PDF export: jsPDF
- Bundler / runtime: Bun (bun.lock included) — npm/yarn work too
